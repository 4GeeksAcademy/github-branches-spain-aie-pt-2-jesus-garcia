# Contexto del proyecto

## Objetivo
Construir una interfaz web con HTML semantico, Tailwind CSS, Schema.org y diseno responsivo.
Para una reconocida marca de ropa con sede en Francia quiere un prototipo visual y funcional para su próxima tienda online.

## Requisitos
- SEO bien trabajado (estructura semántica, contenido indexable, buenas prácticas).
- Diseño moderno y consistente.
- Responsive completo: móvil, tablet y escritorio.

## Alcance actual
- Pagina principal en [index.html](index.html).
- Pagina de catalogo en [catalogue/index.html](catalogue/index.html).
- Pagina de producto en [product/index.html](product/index.html).
- Componentes reutilizables en [shared/layout.js](shared/layout.js).

## Criterios de calidad
- Estructura semantica clara con uso de header, main, section, article y footer cuando aplique.
- Estilos con Tailwind sin romper la visualizacion en movil y escritorio.
- Marcado estructurado con Schema.org cuando sea relevante.
